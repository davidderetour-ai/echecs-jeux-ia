🖥️ Améliorer mon Mac — diagnostic sûr

Alicia peut analyser ton Mac avant de proposer une optimisation : espace libre, mémoire, version du système et compatibilité des logiciels. Elle ne modifie jamais macOS sans ton autorisation.

1. Télécharger le petit diagnostic Mac (lecture seule). 2. Lis le fichier si tu le souhaites. 3. Sur le Mac, ouvre Terminal et saisis bash ~/Downloads/mac-audit.sh. 4. Copie le résultat ci-dessous.

Première amélioration réversible : réduire l’animation du Dock

Cette modification facultative supprime l’animation lors de l’ouverture d’applications depuis le Dock. Elle peut rendre l’interface plus sobre, mais n’accélère pas le processeur et ne change pas la compatibilité de macOS.

Télécharger l’outil Mac de modification contrôlée, puis examiner son contenu avant usage.

  1. Prévisualiser : bash ~/Downloads/mac-improve.sh preview
  2. Appliquer uniquement si tu acceptes : bash ~/Downloads/mac-improve.sh apply
  3. Vérifier : bash ~/Downloads/mac-improve.sh verify
  4. Revenir en arrière : bash ~/Downloads/mac-improve.sh undo

Le script présente exactement ce qu’il fera et demande de saisir OUI ALICIA dans le Terminal pour chaque changement. Il sauvegarde la valeur précédente et ne demande jamais sudo.

Le rapport reste sur ton appareil : aucun envoi automatique. Le diagnostic n’applique aucun changement. Le script d’amélioration distinct ne modifie que le réglage du Dock et uniquement après confirmation explicite dans le Terminal. Une sauvegarde est nécessaire avant toute modification future.
